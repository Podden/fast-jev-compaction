# fast-jev-compaction Claude Code mod

This plugin uses Claude Code function hooks to replace a compaction with the
original messages, minus the search runs whose outcome the assistant already
wrote down. `hooks/fast-jev.ts` is a thin adapter: it reads the plugin options,
finds the TypeSafe key, hands `session.compact` transcripts to the
`fast-jev-compaction` library in `src/` (the plugin folder is the repository
root, so the hook imports it directly) and maps the result back onto session
messages. User and assistant text is never touched.

For every episode (the tool calls between two texts) outside the pinned first
and newest messages, Jev gets one request with that episode as `state` (the
text before, one line per call with the head of its output, the text after)
and one question: does the text after report the result of the calls? An
episode whose keep probability (1 − that answer) is below `keepThreshold` is
replaced by a note listing its calls on one line each; failed calls keep the
first `truncateHeadChars` characters of their error.

Episodes holding under 1000 characters are left alone. An episode too big for
`maxStateTokens` / `maxRequestTokens` gets shorter output heads, then none, and
is left alone if it still does not fit. Token counts are estimated without a
tokenizer, calibrated to land a little above what Jev reports.

The mod is an early-access Claude Code function-hook module. The checked-in
type reference was generated by Claude Code **2.1.274**. Enable the function
hooks surface before installing or loading it:

```sh
export CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1
export TYPESAFE_API_KEY="<your TypeSafe key>"

claude plugin marketplace add tamaratran/fast-jev-compaction
claude plugin install fast-jev-compaction@fast-jev-compaction
```

For local development:

```sh
CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1 claude --plugin-dir .
```

## Configuration

The plugin declares these `userConfig` values in
`.claude-plugin/plugin.json`:

| Option | Default |
| --- | ---: |
| `keepThreshold` | `0.5` |
| `preserveRecentMessages` | `6` |
| `compactAtPercent` | `60` |
| `minReductionRatio` | `0.25` |
| `maxStateTokens` | `25000` |
| `maxRequestTokens` | `30000` |
| `truncateHeadChars` | `300` |
| `maxConcurrentRequests` | `0` |
| `baseUrl` | TypeSafe |
| `model` | `jev-latest` |
| `condenseUrl` | empty (off) |
| `condenseModel` | `qwen3.8:27b` |
| `condenseMinChars` | `4000` |

The TypeSafe key can be supplied as the sensitive `apiKey` plugin option or
through `TYPESAFE_API_KEY`. The environment variable is the recommended
development setup.

To use another System One model, set `baseUrl`; a custom endpoint needs no
key. For a self-hosted decider-4b:

```sh
claude plugin install fast-jev-compaction@fast-jev-compaction   --config baseUrl=http://192.168.107.103:5810/v1/systemone   --config maxStateTokens=24000 --config keepThreshold=0.6 --config maxConcurrentRequests=1
```

Every option except `apiKey`, `compactAtPercent`, `minReductionRatio` and
`model` is passed straight to the library; see the root README for what they
do. The `session.compact` hook sends one request per episode, up to
`maxConcurrentRequests` at a time. If Jev fails, the response is malformed, the
key is unavailable, or the estimated reduction is below `minReductionRatio`,
the hook logs a fallback and delegates to Claude Code's built-in compaction.
The outcome is shown as a toast and logged with the reduction, replaced and
kept episodes, largest state and request count; a `decisions:` line with each
episode's keep probability is logged for diagnosis. The
`turn.complete` hook requests compaction when `context.percent` reaches
`compactAtPercent` after an answered main-thread turn; the request runs once
the dispatch has resolved (inside it the turn still counts as in flight), and
a guard keeps a second one from starting meanwhile.

With `condenseUrl` set, kept episodes of at least `condenseMinChars` are
replaced by a fact note from that model, and their full outputs are written to
`.claude/fast-jev/<timestamp>/<episode>.txt` in the working directory (with a
`.gitignore` of `*`); the note names the file.

Kept messages are handed back without the engine's `handle`, so they are
written as fresh records after the compact boundary and `--resume` reloads the
compacted conversation, not the full one (#89, #145). Subagent and fork
compactions (`agentId`) go to the engine unchanged, and `precompute` is
skipped.

## Scope and caveat

Function hooks are early access and may change between Claude Code releases.
This mod uses the generated declarations from 2.1.274 in
`types/claude-code.d.ts`; regenerate and review that file after a
Claude Code upgrade.
